# Security policy

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/yangjh0127/dsh-stock-quotes-plus/security/advisories/new). Include the affected version and reproduction steps. Redact OAuth tokens, browser session details and account information.

The browser calls same-origin DSH routes for quotes, charts and authorization. The Longbridge SDK stores OAuth credentials on the DSH host. Browser storage contains watchlist entries, display preferences and the search catalog.
